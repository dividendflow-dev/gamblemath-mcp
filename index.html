GambleMath Quantitative Research Lab & MCP Server

GambleMath is an open-access quantitative gambling research laboratory, empirical slot RTP dataset repository (4,363 titles), UKGC regulatory register explorer (489 brands), and stateless Model Context Protocol (MCP) server (https://gamblemath.org/mcp).

Harvard Dataverse: doi:10.7910/DVN/ONCIGH · CERN Zenodo: doi:10.5281/zenodo.24344302 · References Index: gamblemath.org/open-science/citations
